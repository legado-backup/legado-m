# F-P0-2 备份选择器 测试用例

> 借鉴蛋蛋Max 实现，支持备份项选择、书籍缓存备份、封面图集、高亮规则、Web 端备份接口

## 功能概述

| 子功能 | 说明 |
|--------|------|
| 备份选择器 | 备份时勾选具体备份内容（书源/订阅源/规则/配置等） |
| 书籍缓存备份 | 选择具体书籍备份缓存（含章节缓存） |
| 封面图集 | 创建封面图片分组，支持 ZIP 导入/导出，随机切换封面 |
| 高亮规则 | 对话/书名号/括号标注等 12 种预设高亮，支持自定义样式 |
| Web 端备份 | `/backupPreview` 返回 JSON 预览，`/backup` 返回 ZIP 下载 |
| 阅读记录详情 | 备份含设备ID/书名/作者/日期/时长/字数的详细记录 |

**实现文件**：BackupSelectorConfig.kt / BookCacheSelectorConfig.kt / Backup.kt / BackupController.kt / Restore.kt / HttpServer.kt / CoverGalleryRepository.kt / HighlightRuleStore.kt 等 19 个文件

## 测试环境

- 设备：Android 6.0+ 真机
- 构建版本：appDebug
- 数据库版本：Room v90（新增 3 张表）
