# F-P1-8 书源/订阅源分组文件夹视图 测试用例

> **功能模块**：F-P1-8 书源/订阅源分组文件夹布局
> **任务编号**：Task 26.7
> **测试级别**：Level 2（编译通过 + 模块交互）+ Level 3（真机端到端验证）
> **创建日期**：2026-07-07
> **状态**：待真机验证

## 1. 功能概述

为书源管理和订阅源管理界面新增文件夹视图模式：
- 顶部菜单新增视图切换按钮（`menu_view_mode`，文件夹图标）
- 文件夹视图：3 列网格布局，显示"全部"/"未分组"/各分组文件夹卡片
- 点击文件夹 → 自动切换到列表视图并按分组筛选
- 视图模式持久化到 `AppConfig.sourceViewMode`/`rssViewMode`（0=列表，1=文件夹）

### Level 3：端到端验证（真机操作）

#### TC-04 书源 - 默认列表视图
- **前置条件**：首次安装或清除数据后
- **测试步骤**：打开书源管理界面
- **预期结果**：默认显示列表视图（LinearLayoutManager），与原有行为一致
- **验证要点**：菜单按钮显示文件夹图标

#### TC-05 书源 - 切换到文件夹视图
- **前置条件**：书源管理界面已打开，当前为列表视图
- **测试步骤**：点击顶部菜单的文件夹图标按钮
- **预期结果**：
  1. 视图切换为 3 列网格布局（GridLayoutManager）
  2. 显示"全部"/"未分组"/各分组名称的文件夹卡片
  3. 每个文件夹卡片显示文件夹图标 + 分组名
  4. `AppConfig.sourceViewMode` 持久化为 1
- **验证要点**：重新打开书源管理界面，应直接显示文件夹视图

#### TC-06 书源 - 点击"全部"文件夹
- **前置条件**：当前为文件夹视图
- **测试步骤**：点击"全部"文件夹
- **预期结果**：
  1. 自动切换回列表视图
  2. 搜索框清空，显示所有书源
  3. `AppConfig.sourceViewMode` 持久化为 0

#### TC-07 书源 - 点击"未分组"文件夹
- **前置条件**：当前为文件夹视图
- **测试步骤**：点击"未分组"文件夹
- **预期结果**：
  1. 自动切换回列表视图
  2. 搜索框显示"未分组"（或对应本地化文本）
  3. 列表显示未分组的书源

#### TC-08 书源 - 点击分组文件夹
- **前置条件**：当前为文件夹视图，存在至少一个分组
- **测试步骤**：点击某个分组文件夹（如"失效"）
- **预期结果**：
  1. 自动切换回列表视图
  2. 搜索框显示 `group:失效`
  3. 列表显示该分组下的书源

#### TC-09 书源 - 文件夹视图分组数据实时更新
- **前置条件**：当前为文件夹视图

- **预期结果**：返回书源管理界面，文件夹视图自动更新分组列表

#### TC-10 订阅源 - 文件夹视图全流程
- **前置条件**：订阅源管理界面已打开
- **测试步骤**：重复 TC-04 ~ TC-09 的操作
- **预期结果**：行为与书源一致，`AppConfig.rssViewMode` 独立持久化

#### TC-11 视图切换不丢失搜索状态
- **前置条件**：列表视图下搜索了某关键词
- **测试步骤**：
  1. 切换到文件夹视图
  2. 切换回列表视图
- **预期结果**：
  1. 文件夹视图显示全部分组（忽略搜索关键词）
  2. 切换回列表视图时，搜索关键词保留，列表恢复筛选状态

#### TC-12 文件夹视图下拖拽禁用

- **预期结果**：无法拖拽，`itemTouchCallback.isCanDrag = false` 生效，无崩溃
