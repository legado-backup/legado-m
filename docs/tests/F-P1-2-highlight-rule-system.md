# F-P1-2 高亮规则系统 测试用例

> 正则/字面量匹配自动高亮，9 通道样式，手动划线高亮，分组管理，预设规则，导入导出

## 功能概述

阅读时支持正则/字面量匹配自动高亮，9 通道样式（背景色/文字色/加粗/斜体/下划线/删除线/方框/着重号/自定义字体），在阅读界面菜单可进入规则管理页。支持手动划线高亮、分组管理、预设规则库、导入导出。

**入口**：阅读界面 → 菜单 → 高亮规则
**实现文件**：HighlightRule.kt / HighlightRuleStore.kt / HighlightRuleGroupStore.kt / HighlightStyle.kt

## 测试环境

- 设备：Android 6.0+ 真机
- 构建版本：appDebug

## TC-F-P1-2-01：创建字面量高亮规则（正常用例）

**前置条件**：正在阅读一本书

**测试步骤**：
1. 进入阅读界面 → 菜单 → 高亮规则
2. 点击新建规则
3. 名称输入"对话标记"
4. 匹配模式输入"说："
5. 关闭"正则匹配"开关（字面量模式）
6. 设置背景色为黄色
7. 保存

**预期结果**：
- ✅ 规则保存成功
- ✅ 阅读界面中所有"说："文字高亮为黄色背景
- ✅ 规则列表显示"对话标记"
