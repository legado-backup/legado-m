# F-P1-1 自动任务系统 测试用例

> cron 表达式定时执行 JS 脚本，支持自动刷新书籍目录、通知新书更新、自定义通知等

## 功能概述

在「我的」页面可开关自动任务服务并进入任务管理页面，支持任务的增删改、批量设置 Cron、导入导出、拖拽排序、日志查看。借鉴自阅读T（skybbk1001/legadoT）。

**入口**：我的 → 自动任务服务开关 + 任务管理页面
**实现文件**：AutoTask.kt / AutoTaskService.kt / AutoTaskProtocol.kt / AutoTaskRule.kt / AutoTaskActivity.kt / CronSchedule.kt

## 测试环境

- 设备：Android 6.0+ 真机
- 构建版本：appDebug
- 依赖：Kotlin 2.3.10, Room 2.7.1

---

## TC-F-P1-1-01：创建自动任务（正常用例）

**前置条件**：已开启自动任务服务开关

**测试步骤**：
1. 进入「我的 → 自动任务」管理页面
2. 点击新建任务按钮
3. 填写任务名称"测试任务"
4. 输入 cron 表达式 `*/30 * * * *`（每 30 分钟）
5. 输入 JS 脚本 `var __autoTask = {actions:[{type:"notify",title:"测试",content:"Hello"}]}; __autoTask`
6. 保存

**预期结果**：
- ✅ 任务保存成功，列表中显示"测试任务"
- ✅ cron 显示"每 30 分钟"
- ✅ 任务状态为已启用

## TC-F-P1-1-02：创建书籍更新任务（正常用例）

**前置条件**：书架有至少 1 本书

**测试步骤**：
1. 在任务管理页面新建任务
2. 选择"书籍更新"模板
3. 选择一本书籍
4. 设置 cron `0 * * * *`（每小时）
5. 开启通知，最小更新章节数设为 1
6. 保存

**预期结果**：
- ✅ 任务保存成功
- ✅ 脚本自动生成 refreshToc 动作
- ✅ 到时间后自动检查书籍更新
