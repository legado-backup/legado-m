# F-P1-3 调试日志悬浮球 测试用例

> 屏幕悬浮球快速查看应用日志，日志支持按级别（错误/警告/信息/调试）过滤显示

## 功能概述

在「其他设置」开启调试日志悬浮球后，屏幕右下角显示悬浮球，点击可快速查看应用日志。AppLog 数据结构扩展为 LogEntry + Level 枚举（ERROR/WARN/INFO/DEBUG），AppLogDialog 支持按级别过滤。借鉴自蛋蛋Max（简化为传统 View 实现）。

**入口**：其他设置 → 调试日志悬浮球开关
**实现文件**：DebugFloatBallManager.kt / AppLog.kt / AppLogDialog.kt / LifecycleHelp.kt / OtherConfigFragment.kt

## 测试环境

- 设备：Android 6.0+ 真机
- 构建版本：appDebug
