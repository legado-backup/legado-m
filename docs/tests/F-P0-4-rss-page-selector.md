# F-P0-4 订阅源页面选择器 测试用例

> 借鉴蛋蛋Max 实现，在订阅源文章列表中支持页码跳转

## 功能概述

在订阅源文章列表页面（RssArticlesFragment）的菜单中添加"页码"选项，支持输入页码直接跳转到指定页面。

**入口**：订阅源文章列表 → 菜单 → 页码
**实现文件**：rss_articles.xml / RssArticlesViewModel.kt / RssArticlesFragment.kt / RssSortActivity.kt

## 测试环境

- 设备：Android 6.0+ 真机
- 构建版本：appDebug

**测试步骤**：
1. 打开一个订阅源
2. 点击菜单按钮

**预期结果**：

- ✅ 位置在"搜索"之后、"登录"之前

## TC-F-P0-4-02：页码跳转（正常用例）

**前置条件**：订阅源有多页文章

4. 确认

**预期结果**：
- ✅ 加载第 3 页文章列表
- ✅ 菜单标题更新为"第3页"
- ✅ nextPageUrl 正确重置
