# quality-check-unify（体检收编校验所选）

## 概述
源质量体检与"校验所选"全方位对比后（探索结论见对话 2026-09-13），确认体检检测能力为校验所选的超集，但缺"结果落库"能力（失效分组/weight/注释）。本任务补桥接层使体检可完整收编校验所选。

## 核心能力
- **QualityReportApplier 桥接层**：SourceQualityReport → 旧失效分组/weight/注释映射回填（判定核心单一权威源，分组名与 CheckSourceService 完全一致）
- **结果页"应用结果"动作**：体检结果页底栏新增，对选中/筛选集执行落库
- **入口策略**：本期保留"校验所选"入口（deprecated，下一版本清理），仅加桥接

## 对比结论摘要
| 维度 | 校验所选 | 体检 |
|------|---------|------|
| 检测维度 | 书源 6 维 | 书源 6 维+订阅源 6 维（超集） |
| 结果落库 | ✅ 分组+weight+注释 | ❌（本任务补齐） |
| 大规模效率 | 180s 单源超时，千条易卡 | 缓存/限额/去重/豁免/暂停续跑 |
| 后台存活 | 前台服务通知栏 | 进程内单例（弱） |
