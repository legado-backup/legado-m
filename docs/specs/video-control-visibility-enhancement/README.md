# 视频播放器控件显隐与缓冲条优化

> **Spec 状态**：🔄 设计中
> **创建日期**：2026-07-11
> **来源**：用户检查点2反馈（5个反馈中的反馈1+反馈2）

## 功能概述

优化内置视频播放器的两项交互体验：
1. **缓冲进度条可见性修复**（反馈1）：当前缓冲条高度仅 1.5dp 且未绑定 secondaryProgress，用户看不见缓冲进度
2. **控件显隐交互变更**（反馈2）：右侧功能区和左下角名称/全屏按钮从"默认不隐藏"改为"刚开始展示→过段时间隐藏→点击触发显示"，与 GSY 播放器自带播放条/倍速行为一致

## 核心能力

- 缓冲进度条正确显示缓冲百分比（secondaryProgress）
- 控件进入播放器后展示 3 秒，然后自动隐藏
- 单击屏幕切换控件显隐，显示后重新计时 3 秒自动隐藏
- 与 GSY 播放器自带播放条/倍速行为一致
