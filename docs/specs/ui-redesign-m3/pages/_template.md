# 页面设计模板（_template）

> 每页按 DESIGN-MD 交付要求的四要素编写：① 布局结构（文字框图） ② 交互流程 ③ Compose 组件实现思路 ④ 绘图 Prompt。

## 令牌速查（全局引用）

- 栅格基准 360dp；安全边距 16dp；间距档位 **4/8/16/24/32**dp
- 圆角：卡片 18dp、按钮 12dp、输入框 12dp、chip 8dp
- 触控目标 ≥48dp；文本主字号 16sp、次级 14sp、标题 20sp
- 主题：米白(#FAF7F2)/暖黄(#FFF8E1)/纯黑(#121212)/暗夜紫(默认 dark #1E1E32)
- 角标一律 6dp 小圆点，禁用刺眼红数字
- 顶栏：磨砂（背景 0.55 透明度+blur），标题 20sp 主文字
- 新的全局导航：底部 NavigationBar 4 Tab（书架/发现/订阅源/我的）
