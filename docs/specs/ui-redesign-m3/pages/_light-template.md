# 子页面轻量设计文档模板（_light-template · 子页/枝叶页用）

> **适用**：不属于「骨架级样板页 / 已接线核心页」的普通子页（枝叶页）。这些页**继承所属族文档**（`P{族编号}.md`）的骨架/组件/状态范式，本模板只写「继承 + 差异」，避免重复族文档内容造成文档冗余。
> **何时用完整 v2（_template.md）**：骨架级样板页、已接线页、交互复杂/高风险页。判断标准见 ui-standards §10「分档规则」。
> **开发依据**：开发本页时**只读本文档 + 所属族文档 + ui-standards §3.4 规格书**，禁止到 background/ 学习笔记自创样式。
> 编写顺序：继承定位 → 差异点 → 组件 → 三态 → task 对应。
