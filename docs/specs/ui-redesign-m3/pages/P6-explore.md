# P6 发现 / 网络书城（Explore）

> 参考：现状 SourceFolderAdapter 分组网格 + Mihon 封面网格；ExploreShow 书列表。DESIGN-MD 总要求 2 步到达目标。

## 一、布局结构（文字框图）

```
┌──────────────────────────────────┐
│ 磨砂顶栏：搜索框（全局搜索入口 高亮）      │
├──────────────────────────────────┤
│ 分类 Grid 4列（SourceFolder 图标卡片）： │
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐        │
│ │ 图标 │ │图标 │ │图标 │ │图标 │        │
│ │ 名   │ │名  │ │名  │ │名  │        │  ← 2列高、圆角卡片
│ └────┘ └────┘ └────┘ └────┘        │
│ 最近更新（横向 封面水片）            │
└──────────────────────────────────┘
```

## 二、交互流程

| 触发 | 行为 |
|------|------|
| 点分类卡片 | 进 ExploreShowActivity（该书源的书目列表，保留加载/分页） |
| 点搜索框 | 进 SearchActivity 搜索结果页 |
| 长按分类 | 编辑书源/分组 |
| 下拉刷新 | 加载最新书目 |

## 三、Compose 组件实现思路

- 复用：`CoverImage`（Grid 3 列）、`EmptyState`、`SourceFolderCard`（新组件：图标+分类名 2 列）。
- 顶栏搜索：`SearchTopBar`（默认展示输入条，点击跳 SearchActivity）。
- 分类数据复用现状 `SourceFolderViewModel`。
