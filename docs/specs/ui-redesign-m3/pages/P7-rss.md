## 一、布局结构（文字框图·RSS 主列表）

```
┌──────────────────────────────────┐
│ 磨砂顶栏：订阅源(数量)│+添加│编辑     │
├──────────────────────────────────┤
│ 分组 chips（热门/生活/科技...）       │
├──────────────────────────────────┤
│ ┌────────┬────────────────┐       │
│ │ 封面RSS │ 源名 + 文章数    │       │
│ │ 图标    │ 最后更新(灰)     │       │
│ │        ├────────────────┤       │
│ │        │ ●新 n 推送       │ ●小圆点 │
│ └────────┴────────────────┘       │
│ 左滑：收藏 / 置顶 / 删除             │
└──────────────────────────────────┘
```

## 二、交互流程

| 触发 | 行为 |
|------|------|
| 点源 | 进入 RSS 文章列表（RssArticlesFragment） |
| 左滑 | 置顶 / 收藏 / 删除 |
| 长按 | BottomSheet：清空已读/移分组/编辑 |
| 顶栏搜索 | 全局 RSS 搜索 |
| 文章列表 | 点条 → ReadRssActivity（原文阅读） |

## 三、Compose 组件实现思路

- 列表 `LazyColumn` + 卡片复用 P5 风格（线图标 + 源凭证）。
- 与书籍相同的 `BadgePill` 小圆点标注未读，替代红数字。
- 分组 chip + 项间 8dp 中距已有组件。
- 阅读页保持整体现状（WebView 阅读正文不改），只改入口与容器风格。
