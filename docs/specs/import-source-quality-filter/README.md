# 导入源质量过滤与公共源质量校验组件（import-source-quality-filter）

## 功能概述

将书源/订阅源质量校验抽象为**公共组件**（SourceQualityChecker 单源探测核心 + 评分算法 v2），统一服务两大场景：

1. **导入过滤**：导入书源/订阅源时自动探测可用性，过滤确定性失效的低质量源，复核窗口保证**零静默误伤**（默认关闭）
2. **存量体检**：库内存量源批量质量体检，得分排序+状态筛选，辅助快速删除/禁用低质量源（体检只读，删除需显式确认）

## 核心能力

1. **公共组件**：SourceQualityChecker（suspend 单源校验器，零写库副作用，剥离自 CheckSourceService 探测核心），三场景分流消费（导入/体检/现有校验服务）
2. **评分算法 v2**：按源形态分维度模板（书源 4 模板/订阅源 3 模板）+ 已校验维度归一化计分 + 覆盖度展示；消除现有算法的形态歧视（file/video/纯发现源）与系统性误判（登录源/jsLib/源变量/webView 依赖 → suspect 存疑标注）
3. **三级校验**：L1 静态结构检查（0 网络成本）→ L2 快速联网校验（域名+搜索/列表/发现试采）→ L3 深度校验（详情/目录/正文，可选）
4. **确定性失败过滤**：三档严格度；网络异常存疑放行；suspect 源强制放行；过滤判定基于证据而非分数
5. **零静默丢弃**：导入 FILTERED 复核窗口可恢复；体检删除需多选+二次确认
6. **千条集合性能**：Semaphore 并发 + host 域名缓存 + 同 URL 去重 + 同 host 试采限额 + 单源硬超时 + 实时进度与取消
