# 日志系统升级改造

> 状态：**开发中** ｜ 创建：2026-09-06 ｜ 路径：扩展路径（检查点 1 已通过，2026-09-06）

## 功能概述

对现有日志系统进行系统级升级，解决两类核心问题：

1. **测试包日志不够细**：AI 真机测试依赖 `adb logcat -s <TAG>` 与 logs.zip 采集日志解析分析，但当前 `putDebug/putDebugWithTag`（约 377 处调用点）受 `recordLog` 开关守卫（默认 false）直接丢弃，文件写入也由该开关控制，导致测试包默认状态下日志信息量严重不足。
2. **日志管理能力碎片化**：内存日志（AppLogDialog）、崩溃日志（CrashLogsDialog）、保存日志、堆转储分散在 3 处入口，缺失关键字搜索、单条/多选删除、文件日志列表查看、导出单条、一键清除等能力。

## 核心能力

| 能力 | 说明 |
|------|------|
| 测试包详细日志默认开启 | `recordLog` 默认值按包类型区分：debug 包默认 true，release 默认 false |
| DEBUG 级日志完整落盘 | recordLog 开启时 DEBUG 级进内存+写文件（当前关闭即丢弃） |
| 内存日志容量提升 | 100 → 500 条（AI 解析场景需要更大回溯窗口） |
| 全屏日志管理中心 | 新增 LogActivity：应用日志/崩溃日志/文件日志/堆转储 4 Tab 统一管理 |
| 日志操作增强 | 关键字搜索、级别筛选、多选删除、单条详情、分享导出、一键清除（含确认） |
