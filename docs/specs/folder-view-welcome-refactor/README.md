## 功能概述

本次改造针对用户反馈的三大问题：

1. **书源/订阅源文件夹视图样式丑陋**：当前实现是 120dp 主题色色块 + `ic_folder` 图标，与书架成熟的书封卡片样式严重割裂。本次将彻底重构，复用书架网格分组卡片样式（3:4 比例 + 首字占位 + 主题色渐变），并新增"分组样式/视图/排序/间距"配置对话框。

2. **欢迎页自定义功能不完善**：现有 `customWelcome` 开关默认关闭，且缺少"按比例裁剪"逻辑。本次将默认改为开启，并在用户选择图片时按屏幕比例居中裁剪，保证全屏背景不变形。

3. **3.7 版本后前端交互缺乏整体审计**：07/05~07/07 新增 8+ 个前端交互功能（自动任务/高亮规则/调试悬浮球/调试工具集等），本次输出审计报告，识别过重/偏离核心的功能，给出精简或迁移建议。

## 核心设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 文件夹卡片内容 | 首字 + 主题色渐变 | YAGNI：不为分组新增 cover 字段；视觉与书架统一 |
| 配置对话框实现 | SourceFolderAdapter 伴生对象 `showConfigDialog()` | 避免重复代码，不过度抽象 |
| 欢迎页裁剪比例 | 屏幕比例（运行时获取） | 欢迎页是全屏背景，按屏幕裁剪保证不变形 |
| customWelcome 默认值 | true | 新用户开箱即用；无图片时自动回退默认欢迎页 |
| 3.7 后交互改动 | 同步实施 3 项精简（Cron简化/悬浮球隐藏/调试工具迁移） | 用户审核选择；范围可控 |
| 文件夹视图默认模式 | 保持列表视图（sourceViewMode=0） | 尊重现有用户习惯 |

## 替代方案（否决）

| 方案 | 否决理由 |
|------|---------|
| 为分组新增 cover 字段 | 过度设计，需改 schema + DAO + 编辑界面 |
| 沿用 ic_folder 但换精美图标 | 治标不治本，仍是"图标+色块"风格 |
| 直接复用 BooksAdapterGrid 类 | 耦合过深，绑定 Book/BookGroup 实体 |
| 欢迎页按 iv_book 方形比例裁剪 | 误读需求，欢迎页是全屏背景 |
| 本次直接实施交互改动 | 范围爆炸，应单独 spec |

## 已知缺点

| 缺点 | 接受理由 |
|------|---------|
| 首字封面不如真实图片精美 | YAGNI，零成本且风格统一 |
| 配置对话框新增 4 项增加认知负担 | 用户明确要求，默认值合理不影响新手 |
| 欢迎页默认开启可能让老用户突兀 | 可关闭；无图片时自动回退默认 |
| 3.7 后交互仅同步实施 3 项精简 | "迁移"类（封面图集）工作量大，由后续 spec 决策 |
| 按屏幕比例裁剪丢弃边缘内容 | 居中裁剪保留主体；裁剪本质取舍 |
