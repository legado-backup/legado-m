# Git多远程仓库隔离方案

## 功能概述

实现 **私仓开发（含AI文档）+ 公仓开源（仅源码）** 的Git多远程仓库隔离机制，通过Git分支隔离 + pre-push Hook门禁，确保AI相关文档和敏感配置不被推送到公开仓库。

## 核心能力

- **双远程仓库管理**：私有仓库（全量代码）+ 公开仓库（脱敏开源版本）
- **分支隔离策略**：`master-private`（私仓分支）与 `master-public`（公仓分支）物理隔离
- **Git Hook门禁**：pre-push自动检测敏感文件，拦截违规推送
- **敏感文件清单化**：`.trae/`、`ai_tests/`、`AGENTS.md`、`google-services.json` 等统一管理
- **一次性历史清理**：BFG Repo-Cleaner清理历史提交中的敏感信息
