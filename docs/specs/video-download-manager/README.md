# 视频下载与下载管理整合

## 功能概述

本功能将当前「下载管理」从「仅存在于精准管理页、依赖系统 DownloadManager、无内容消费入口」的死角状态，重构为**具象可用的下载子系统**：

1. 在内置视频播放器右侧操作栏（全屏 / 收藏 / 设置）新增**下载按钮**，一键把当前正在播放的视频加入下载。
2. 自研**多线程分片下载引擎**（对齐 IDM 的 Range 分片逻辑），替代系统 DownloadManager，支持直链 mp4/mkv/flv 等格式的快速分片下载。
3. 支持 **m3u8/HLS 流**：分片下载 ts → 合并 → 转 **mp4** → 下载完成后自动清理分片中间文件。
4. 下载默认文件名 = 当前视频标题，纳入现有「下载管理」页面展示（正在下载 / 已完成等分类 Tab 保留）。

## 核心能力

| 能力 | 说明 |
|------|------|
| 播放器入口 | 视频播放器右栏「下载」按钮，使用当前已解析视频 URL + 防盗链头 + 视频标题 |
| 多线程分片 | 直链按 Range 多片并发下载，Part 临时文件 + 顺序合并，非 Range 服务器自动降级单线程 |
| m3u8 转 mp4 | 解析清单 → 并发下载分片 → 合并为 ts → 平台 MediaExtractor/MediaMuxer 重封装为 mp4 → 清理中间产物 |
| 下载管理 | 复用现有 DownloadManageActivity，展示 全部/正在/暂停/完成/失败 分类，支持暂停/重试/删除/打开/清理 |
| 默认命名 | 下载文件名默认为视频标题，重复自动加序号避免覆盖 |
