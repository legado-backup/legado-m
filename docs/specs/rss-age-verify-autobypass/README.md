# RSS 订阅源年龄验证自动绕过

> 状态: 🔄 设计中

## 功能概述

优化含服务端年龄验证（18+弹框）的 RSS 订阅源，实现无需用户手动点击即可自动破除验证页面，直接获取真实内容。

## 核心能力

- 分析目标站点的年龄验证机制（服务端Cookie/前端JS/重定向等）
- 通过 `header` 字段预置验证Cookie，实现 OkHttp 层自动绕过
- 通过 `loginCheckJs` 字段实现 OkHttp 层检测+自动请求验证URL
- 通过 `injectJs` 字段实现 WebView 层自动点击确认按钮
- 三层防护确保 OkHttp + WebView 两种加载模式下均无需用户交互
