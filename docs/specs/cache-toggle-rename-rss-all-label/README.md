# 文案调整：视频缓存开关改名 + 订阅「全部」分组标签缩短

> 状态：✅ 已完成（2026-08-30，检查点1/2/3 全过；L2 真机验证经用户裁决跳过，后续真机自行体验确认）

## 功能概述

两项纯文案（字符串资源）调整，零逻辑变更：

1. **视频播放器设置「边下边播」改名**：该开关实际是 ExoPlayer SimpleCache 的播放缓存策略总开关（开启=播放时写磁盘缓存，关闭=直连不缓存），且播放器现已新增独立的「下载」按钮，「边下边播」名称易与之混淆。改名为「播放时缓存」，准确表达"这是播放过程中的缓存策略，不是下载"。
2. **订阅源分组标签「全部分组」缩短为「全部」**：订阅页标签栏/文件夹视图中表示"所有分组"的特殊文件夹名称，四个字过长，缩短为两个字更简洁。

## 核心能力

- `cache_play` 字符串文案变更（仅视频设置面板一处 UI 引用）
- `all_groups` 字符串文案变更（仅订阅页 RssFragment + SourceFolderAdapter 引用，后者按资源 ID 比对封面 key，改文案不影响封面映射）
