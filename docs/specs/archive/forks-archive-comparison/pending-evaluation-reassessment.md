# 36 项待评估项的用户价值重评估

> **生成时间**：2026-07-18
> **触发原因**：用户反馈"36 个待评估的，你也要评估呀，大哥！！！"
> **评估标准**：与 user-value-reassessment.md 相同（用户直接感知 40% + 用户核心场景 30% + 实施成本 vs 用户收益 20% + 用户额外负担 10%）
> **评估目标**：将 36 项待评估项重新分类为：升级为借鉴（P0/P1/P2）/ 保持待评估 / 改为不借鉴

---

## 一、评估方法论

### 1.1 评分规则

| 综合评分 | 决策 | 说明 |
|---------|------|------|
| ≥4.0 分 | 升级为借鉴 | 用户高收益 |
| 3.5-3.9 分 | 保持待评估 | 中等价值，需进一步评估 |
| ≤3.4 分 | 改为不借鉴 | 用户收益小 |

### 1.2 特殊规则

- **AI 模块全部改为不借鉴**（用户明确反对）

- **DEPS 视觉特效类**：已在 v3.0 否决，保持不借鉴

## 十一、关键结论

### 11.1 36 项待评估的核心发现

5. **8 项保持待评估**：需用户反馈或兼容性评估
6. **19 项改为不借鉴**：用户收益小或偏离核心场景

- **借鉴 45 项**（P0: 10 / P1: 23 / P2: 12）
- **不借鉴 65 项**（偏离主航道 / 已有更优实现 / 体量过大 / 已知 Bug / 用户收益小）
- **待评估 8 项**（需用户反馈或兼容性评估）

1. **118 项决策全部评估完成**，无遗漏

4. **用户额外负担是重要减分项**：需 API key 的功能全部否决
