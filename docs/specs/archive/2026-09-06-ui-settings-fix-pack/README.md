# ui-settings-fix-pack（UI 设置体验修复包）

> 状态：**✅ 已完成（2026-09-06 用户验收通过，归档于 docs/specs/archive/2026-09-06-ui-settings-fix-pack/）** ｜ 路径：扩展路径 ｜ 创建：2026-09-06

## 功能概述

修复三项 UI 设置体验问题：
1. **F1 主界面底栏搜索框显隐**：隐藏功能已存在但入口过深（仅 floating 模式底栏管理编辑对话框内），新增"我的设置页"快捷开关，配置单源互通
2. **F2 字号放大组件适配**：fontScale 1.4x~1.6x 时固定高度组件文字截断，实测清单驱动逐点修复，1.0x 零回归
3. **F3 取色器恢复**：恢复被 3c8aa5c7b 误删调用链的优化版取色器 ColorPickerSheet，替换主题编辑页简版弹窗，扩展"跟随默认"支持

## 核心能力

- 设置页快捷开关 → 主界面悬浮搜索框即时显隐（复用既有 pref 与生效链）
- 大字号模式核心页面无文字截断
- 主题编辑取色体验回归优化版（预置色板 + HSL 滑块 + 活预览）
