## 如果验证失败

如果新对话中AI加载的规范仍然是旧版本（含md标记/emoji/表格）：

1. 可能是系统缓存未刷新 → 重启 Trae CN
2. 可能是文件写入失败 → 检查文件实际内容
3. 可能是系统注入时机问题 → 系统在对话开始时固定注入，修改后需开新对话

## Trae CN 规则加载机制（基于WebSearch）

- 全局规则在 `~/.trae-cn/user_rules/`，项目规则在 `.trae/rules/`
- always-applied 规则每次对话自动加载到 context
- 系统注入在对话开始时固定，修改文件后需开新对话验证
- 规则文件按修改时间从旧到新加载，限制约12KB
