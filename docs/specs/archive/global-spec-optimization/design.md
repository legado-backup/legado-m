# design.md

## 1. 格式压缩规则

### 1.1 标记去除规则

| 标记类型 | 当前 | 目标 | 说明 |
|---------|------|------|------|
| 标题 | `## 标题` | `标题` | 去掉#前缀 |
| 表格 | `| col1 | col2 |` | `col1: col2` | 冒号分隔 |
| emoji | `❌` `✅` `🚨` | 无 | 全部去掉 |
| 代码块 | ` ```code``` ` | 直接缩进4空格 | 去掉```标记 |
| 分隔线 | `---` | 空行 | 去掉--- |
| 列表 | `- item` 或 `1. item` | 紧凑排列 | 同行分号或逗号分隔 |
| 引用 | `> text` | 直接正文 | 去掉> |
| 粗体 | `**text**` | `text` | 去掉** |

### 1.2 空行压缩规则
- 文件首尾不留空行
- 同一小节内不留空行
- 小节之间留1个空行（最多1个）
- 表格行之间不留空行

- 调整方式重新设计工具调用,避免再次触发

是否含敏感字段?→隐藏

是否含原始日志全文?→提取关键技术信息

```
