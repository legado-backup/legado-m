## Approach

### 四大优化策略

**策略1：格式极致压缩（预计节省1200字符）**
- 去掉所有emoji（❌/✅/🟡/🔴/🚨等）
- 表格改为紧凑行格式（`规则: 说明`）
- 去掉分隔线（---）
- 去掉代码块标记（```）
- 减少空行（同类内容紧凑排列）
- 去掉标题#标记（首行用关键词标识）

**策略2：内容去冗余（预计节省600字符）**
- 合并core-spec.md的表格（核心规范表+子规范表）
- AskUserQuestion规则只在core-spec.md保留，其他文件引用
- 精简每个文件的"反模式"小节（改为紧凑行内列表）
- 去掉跨文件重复的描述性文字

**策略3：AI主动使用强化（不增加字符，优化措辞）**
- user_rules.md首行增加强制指令："对话开始→Read core-spec.md→检查触发条件→加载子规范"
- core-spec.md子规范表用强制性措辞："遇到X时必须Read Y.md（不加载=违规）"
- 增加触发条件自查清单（AI对话开始时自动检查）

**策略4：openspec-workflow大幅简化（预计节省634字符）**
- 用户平时使用 `/openspec` 指令，指令内容会注入上下文（包含完整8步工作流程）
- 只有用户文字描述提到"openspec"时才需要按需加载
- openspec-workflow.md简化为"引用提示"：当文字提到openspec时，Read commands/openspec.md
- 从784字符简化为150字符的引用提示

**策略5：AI执行力度强化（不增加字符，优化措辞，基于2026-07-14实战教训）**
- 问题根因：AI知道规范但不执行（如AskUserQuestion响应后不持久化）
- user_rules.md首行增加执行锚点："AskUserQuestion响应后第一动作：写入项目记忆（非可选，未写入禁止继续工作）"
- core-spec.md的AskUserQuestion规则强化执行顺序：明确"写入项目记忆是第一优先级，非可选步骤"
- context-recovery.md增加执行检查点："执行前自检：是否已写入项目记忆？未写入则禁止继续工作"

### 压缩恢复闭环设计（核心要求）

参照老版本最全描述（temp_extract2/core-spec.md §1.1-1.9 + rule-1783687915667.md 第1节），确保压缩恢复流程完整闭环：

```
压缩触发
  ↓
并行读取四件套（项目主规范+项目记忆含反馈记录+任务列表+经验索引）
  ↓
四件套就绪？
  ├─ 是 → 输出双重验证清单：
  │       ① 已加载项目主规范（路径+强制规则清单）
  │       ② 已加载用户反馈清单（最近7天）+ 声明严格遵守
  │       → 检查经验索引是否有当前任务历史决策
  │           ├─ 有 → 加载历史上下文后从当前任务继续工作
  │           └─ 无 → 从当前任务列表状态重新建立上下文
  └─ 否 → 暂停工作，向用户报告缺失项（禁止强行续接）
```

闭环关键环节（必须全部包含）：
1. 四件套并行读取（项目主规范+项目记忆+任务列表+经验索引）
2. 主动读取core-spec.md文件本身（解决系统注入滞后）
3. 输出双重验证清单（项目主规范+用户反馈清单）
4. AskUserQuestion响应处理（复述+原文复述意见+写入项目记忆+继续工作）
5. 用户反馈持久化（AskUserQuestion响应/批评/纠正/决策后立即写入项目记忆）
6. 任务状态权威源规则（TaskList工具为准，tasks.md为副本）
7. 经验持久化要求（每个Phase完成后写入经验索引）

## Scenarios

### 场景1：新对话开始
- AI收到用户消息
- 系统注入user_rules.md等核心文件
- user_rules.md首行强制指令触发AI Read core-spec.md
- core-spec.md的触发条件自查清单引导AI检查场景
- AI根据触发条件Read对应子规范
- AI确认已加载规范后开始工作

### 场景2：上下文压缩恢复（闭环流程）
- 压缩触发
- AI并行读取四件套（含主动Read core-spec.md文件本身）
- AI输出双重验证清单（项目主规范+用户反馈清单）
- AI声明"以上反馈将在本次会话中严格遵守"
- AI检查经验索引，从当前任务状态恢复工作

### 场景3：OpenSpec任务（两种触发方式）
- 方式1：用户使用 `/openspec` 指令 → 指令内容自动注入上下文（含完整8步流程）
- 方式2：用户文字描述提到"openspec" → AI识别触发条件 → Read openspec-workflow.md → 获取引用提示 → Read commands/openspec.md

### 场景4：AskUserQuestion响应持久化
- 用户通过AskUserQuestion给出响应
- AI复述用户选择
- 若用户选"需调整"并通过Other输入意见，AI原文复述意见
- AI将响应写入项目记忆文件的"用户反馈与决策记录"小节
- AI继续执行后续工作
