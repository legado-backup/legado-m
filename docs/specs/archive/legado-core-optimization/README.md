## 功能概述

对 Legado（阅读M）项目进行全面深度代码质量审计后，识别出 8 大优化方向，涵盖内存安全、线程安全、数据库性能、错误处理、测试覆盖、代码结构、废弃API清理和安全加固。本优化计划旨在系统性解决项目长期积累的技术债务，提升应用稳定性、可维护性和安全性。

## 核心能力

- **内存泄漏治理**：消除全局单例对 Activity/Context 的强引用泄漏
- **线程安全统一**：消除 synchronized+Mutex 混用，统一协程友好的锁策略
- **ANR 根治**：消除数据库主线程查询，确保 IO 操作异步化
- **错误处理规范化**：统一日志体系，消除生产代码崩溃风险
- **测试基础建设**：为核心模块建立最小可运行的测试覆盖
- **大文件拆分**：拆分 3 个>950 行的核心文件，降低维护成本
- **废弃API清理**：迁移 ProgressDialog，推广 DiffUtil
- **安全加固**：SSL 证书验证分级策略
