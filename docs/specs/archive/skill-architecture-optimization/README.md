# Legado Source Creator Skill 架构优化

> **状态**：✅ 已完成（2026-06-12）
> **创建日期**：2026-06-12
> **最后更新**：2026-06-12

---

## 功能概述

对 `legado-source-creator` Skill 进行系统性架构优化，解决四大核心痛点：

1. **经验不复用**：AI 每次从零分析源码，历史经验无法有效检索和复用
2. **临时脚本泛滥**：98 个临时 .py 文件，固化率仅 5.1%，写完即弃
3. **无可调试测试环境**：Python 模拟覆盖率仅 35-40%，JS 规则 0%，"自测通过"但用户导入手机后仍不可用
4. **不主动反哺**：Phase 5 执行率仅 10-20%，经验无法沉淀和进化

---

## 核心能力

| 能力 | 说明 |
|------|------|
| **basic-memory 经验引擎** | 利用 basic-memory MCP (project=legado) 的向量搜索+知识图谱，实现经验语义检索和关联发现 |
| **金字塔架构** | L1(SKILL.md) → L2(references/) → L3(basic-memory) → L4(源码)，逐层递进 |
| **JVM 规则引擎仿真器（增量式 MVP）** | MVP1(Rhino桥接) → MVP2(+jsoup CSS) → MVP3(+hutool加密) → MVP4(+AnalyzeRule)，每步独立可用 |
| **可信度分层验证** | 验证结果标注可信度（高/中/低/不可验证），避免"自测通过但手机不可用" |
| **固化脚本体系** | 将 98 个临时脚本中的可复用模式固化为参数化脚本，先纯 Python 版本，后加 JVM 支持 |
| **权威源双写** | Skill 文档为权威源，basic-memory 为索引层，双写顺序保证一致性 |
| **流程内嵌检查** | 检查清单嵌入 SKILL.md 流程，basic-memory 执行证据不可抵赖 |
| **审计者 Skill** | 任务完成后审计 basic-memory 执行记录，输出审计报告 |

## 8大保证机制

| # | 保证机制 | 解决什么问题 |
|---|---------|------------|
| 1 | **增量交付** | JVM 仿真器 MVP1-4 独立可用，避免"全有或全无" |
| 2 | **验证前置** | 向量搜索效果验证前移为 P0，避免在错误方向投入 |
| 3 | **可信度分层** | 验证结果标注可信度，避免"自测通过但手机不可用" |
| 4 | **权威源规则** | Skill 文档为权威源，双写顺序保证一致性 |
| 5 | **流程内嵌检查** | 检查清单嵌入 SKILL.md，AI 执行 Phase 时即可见 |
| 6 | **执行证据** | basic-memory 写入提供不可抵赖的执行记录 |
| 7 | **审计后置** | 任务完成后审计，发现跳步而非阻止跳步 |
| 8 | **降级路径** | 每个关键组件都有降级方案 |

### 降级路径一览

| 组件 | 正常模式 | 降级模式 | 触发条件 |
|------|---------|---------|---------|
| basic-memory | 向量搜索经验 | 手动 Grep 搜索 references/ | MCP 不可用或搜索效果差 |
| 向量搜索 | hybrid 语义搜索 | tags+metadata 精确过滤 | 召回率 < 70% |
| JVM 仿真器 | MVP4 完整规则引擎 | MVP1-3 轻量验证 | AnalyzeRule 适配失败 |
| JVM 仿真器 | JVM 验证 | Python 仿真 | JDK 不可用或 JAR 启动失败 |
| 双写 | Skill 文档 + basic-memory 同步 | 仅更新 Skill 文档 | basic-memory 写入失败 |
| 审计者 | 任务后审计 | 无审计 | 审计者 Skill 不可用 |

## v2 设计修复的5个致命缺陷

| # | 致命缺陷 | v1 问题 | v2 修复 |
|---|---------|--------|--------|
| 1 | JVM 仿真器"全有或全无" | 瀑布式路径，AnalyzeRule 失败则全盘皆输 | 增量式 MVP1-4，每步独立可用 |
| 2 | 审查者约束力为零 | 独立 Skill 依赖 AI 主动调用 | 流程内嵌检查 + 执行证据 + 任务后审计 |
| 3 | 双写一致性无保证 | 两处数据可能不一致 | 权威源规则 + sync_status + 双写顺序 |
| 4 | 向量搜索未验证 | 中文术语搜索效果未知 | 验证前置为 P0，最小可用迁移集5条先验证 |
| 5 | MockJsExtensions 行为差异 | ajax() 差异可能导致误判 | 差异分析 + 可信度标注 + 分层验证 |
