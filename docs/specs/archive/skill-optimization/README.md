## 功能概述

legado-source-creator skill 经多轮反哺积累，存在大量孤岛文档/脚本（不再使用、已被替代）。用户要求**更彻底地删除孤岛**而非合并重组，并新增网站分析报告作为AI工作笔记。**v6 补充经验检索机制和源码阅读步骤**，**v7 新增偏好优先级机制**，**v8 新增自进化沉淀闭环+经验质量标准+初始化经验审计+陷阱去站点化**，确保AI在经验不足时能主动查找经验或阅读开源阅读源码（只读不改），并能将新发现反哺到 skill 知识库实现自进化。

1. **精简的 SKILL.md**（≤260行）：frontmatter + AI手动操作工作流 + Top 10速查 + 必填字段清单 + 索引链接 + **6大新增章节**（经验检索两源/视频源速查/快速入门/源码阅读/偏好优先级/自进化沉淀）

## 核心目标

**让AI使用skill干活时越干越顺手**（AI自驱视角，非用户审查视角）：
- AI用经验检索两源查找同类经验 → 失败时阅读源码（只读不改） → 发现新范式反哺到 references/（自进化沉淀）
- AI用Playwright MCP分析网站 → 输出报告（防压缩丢失，经验来源用通用范式名标注）
- AI基于报告+经验手动写源JSON → 对照必填清单校验 → 按偏好优先级递进尝试
- AI用ai_tests/scripts/脚本真机验证 → 失败时查陷阱库手动修复 → 修复方案沉淀为陷阱条目
- 全程AI自驱完成，无需Python库辅助，skill 越用越智能
