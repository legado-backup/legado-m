#### ADR-001：BUILD-B-06/07/08 计数方式

- **背景**：spec.md/tasks.md 按"任务包 1 项"算，final-adjustment.md §5.3 按"决策ID 3 项"算
- **决策**：统一为"按任务包 1 项"（spec.md/tasks.md 现状）

- **影响**：总数 54 项保持不变

#### ADR-002：EPUB-B-06 vs EPUB-E-03 功能重复处理

- **背景**：两者均为"分页缓存架构"，EPUB-E-03 依赖 EPUB-B-06
- **决策**：明确分工
  - EPUB-B-06：基础分页缓存机制（内存缓存）

#### ADR-003：EPUB-B-07 vs EPUB-E-05 功能重复处理

- **背景**：EPUB-B-07 包含"错误回退+文本选择器"，EPUB-E-05 是"错误回退机制"
- **决策**：拆分 EPUB-B-07
  - EPUB-B-07：仅保留"文本选择器"
  - EPUB-E-05：错误回退机制（含用户提示 UI）
- **影响**：spec.md §4.3.2 REQ-P2-009 描述需更新，tasks.md 3.2.6 子任务需调整

#### ADR-004：P0 实施窗口调整

- **决策**：调整为"2 周内"
- **影响**：spec.md §4.1 / tasks.md §1 / §5.1 检查点 1 时间窗口
