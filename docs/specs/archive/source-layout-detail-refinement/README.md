# 书源/订阅源布局细节优化 + 视频播放细节优化

> 处理用户反馈的 7 类细节不符：书源/订阅源分组样式/分组类型/订阅源二级设置/搜索框/视频缓存/视频倍速/其他

## 功能概述

context-compression-feedback-preservation spec 审查发现：F1-F10 代码全部已实施，但用户指出"功能可用但细节不符"。本 spec 专门处理用户反馈的 7 类细节不符项，使功能符合用户设想。

## 7 类细节不符项

### 布局细节（D1-D4）

| 编号 | 用户反馈 | 当前实现 | 期望实现 |
|------|---------|---------|---------|
| D1 | 书源/订阅源分组样式应像书架"标签+分组"两模式 | source_group_style_new 是"列表/按类型/按分组"三选项（数据归类） | 标签模式（Tab平铺）+ 分组模式（文件夹），参考 BookshelfFragment1/2 |
| D2 | 分组类型要有"源类型"+"源分组"两维度 | 单一维度（按类型 OR 按分组） | 源类型（文本/图片/视频）+ 源分组两维度组合 |
| D3 | 订阅源二级设置页面还原默认列表展示 | 文件夹/布局概念延伸到二级页面 | 布局概念只在首屏使用，二级页面还原列表 |
| D4 | 搜索框参考书架实现 | 当前搜索框未充分利用标签/分组 | 参考书架 SearchView 实现 |

### 视频细节（D5-D6）

| 编号 | 用户反馈 | 当前实现 | 期望实现 |
|------|---------|---------|---------|
| D5 | 视频缓存大小支持用户调整（下拉选择），不能固定 100mb | **已有设置入口**（SettingsDialog.kt 50/100/200/500 MB 单选对话框），但用户找不到/想要下拉 | 设置入口更明显 + 改为 Spinner 下拉选择 |
| D6 | 视频倍速 15x 有问题（之前分析 10x+ 有问题），需限制或修复 | 最高 15x，15X 音频失真（ExoPlayer 限制） | 限制最高倍速或修复高倍速音频问题 |

### 其他（D7）

| 编号 | 用户反馈 | 状态 |
|------|---------|------|
| D7 | "还有其他好多的" | 待用户继续列举，本 spec 预留扩展 |

## 核心能力

1. **书源/订阅源标签+分组两模式**：参考书架 BookshelfFragment1（标签）/BookshelfFragment2（文件夹）实现
2. **源类型+源分组两维度分组**：支持文本/图片/视频类型 × 源分组字段组合筛选
3. **订阅源二级设置还原列表**：布局概念只在首屏使用
4. **搜索框参考书架**：充分利用标签/分组
5. **视频缓存下拉选择**：设置入口明显化 + Spinner 下拉
6. **视频倍速问题处理**：限制最高倍速或修复高倍速
