# Spec: 书源/订阅源布局细节优化 + 视频播放细节优化

## Intent

用户反馈 F1-F10 代码全部已实施，但"功能可用但细节不符"。本 spec 处理用户明确反馈的 7 类细节不符项，使书源/订阅源布局和视频播放功能符合用户设想。

核心问题：之前的设计虽然实现了功能，但展示模式、分组维度、设置入口等细节与用户的设想存在偏差。

## Scope

### In Scope

**布局细节（D1-D4）**：
- D1: 书源/订阅源分组样式新增"标签+分组"两模式（参考书架 BookshelfFragment1/2）
- D2: **修复按类型分组一级页面不生效的 bug**（用户反馈"从来都没有成功过"）+ 支持"源类型(文本/图片/视频)+源分组"两维度组合
- D3: 订阅源二级设置页面还原默认列表展示（布局概念只在首屏使用，右侧菜单类型分类有效但用户要求二级页面改回原来的）
- D4: 搜索框参考书架实现（充分利用标签/分组）

**视频细节（D5-D6）**：
- D5: 视频缓存大小设置入口明显化 + 改为 Spinner 下拉选择（当前已有 50/100/200/500 MB 单选对话框，但用户找不到）
- D6: 视频倍速保留 15x 不动（用户选方案C，不处理音频失真）

**其他（D7）**：
- D7: 预留扩展，用户"还有其他好多的"待继续列举

### Out of Scope

- 重新设计书架布局（书架 BookshelfFragment1/2 已完善，本 spec 只参考其实现模式）
- 视频播放器底层架构重构（边下边播已由 ExoPlayer SimpleCache 接管，cachePlay 已废弃）
- 书源/订阅源数据模型变更（BookSource/RssSource 实体不改）

### Alternatives Considered

1. **拆分为两个 spec**（布局 + 视频）→ 否决：用户明确要求一个 spec 处理 7 类细节不符
2. **只处理 D1-D4 布局，D5-D6 视频另开 spec**→ 否决：用户反馈是一个整体，不应拆分
3. **D5 视频缓存重新设计**→ 否决：当前已有 SettingsDialog 设置入口，只需优化 UI（改为下拉）和入口可见性

### Drawbacks

- D1 标签+分组两模式需要较大 UI 改动，可能引入新的 Fragment 结构
- D6 限制最高倍速可能影响部分用户的高速浏览需求（但 15x 音频失真更影响体验）
- D2 源类型维度需要确认 BookSource/RssSource 是否有 type 字段区分文本/图片/视频

## Approach

### D1: 标签+分组两模式

参考书架实现：
- **标签模式**（类似 BookshelfFragment1）：用 TabLayout 平铺展示分组标签，选择标签后展示该分组下的源
- **分组模式**（类似 BookshelfFragment2）：分组作为文件夹卡片展示在首屏，点击文件夹进入查看该分组下的源

新增配置项 `sourceGroupMode`（0=标签模式, 1=分组模式），与现有 `sourceGroupStyle`（列表/按类型/按分组数据归类）正交。

### D2: 源类型+源分组两维度

在分组/筛选时支持两维度组合：
- 源类型维度：文本/图片/视频（需确认 BookSource 的 type 字段）
- 源分组维度：源的字段分组信息（BookSource.group / RssSource.group）

### D3: 订阅源二级设置还原列表

订阅源首屏使用布局概念（标签/文件夹），但点击进入二级页面后还原为默认列表展示，不延续文件夹/布局概念。

### D4: 搜索框参考书架

参考 BookshelfFragment1/2 的 SearchView 实现，让搜索框与标签/分组模式配合。

### D5: 视频缓存下拉选择

当前 SettingsDialog.kt 已有缓存容量选择（50/100/200/500 MB 单选对话框），优化为：
1. 改为 Spinner 下拉选择（用户明确要求"滚动下拉选择"）
2. 设置入口更明显（当前在视频播放界面设置对话框中，用户找不到）

### D6: 视频倍速保留 15x 不动

用户选方案C，保留 15x 不动，不处理音频失真问题。本项无需代码修改。

## Requirements

### 功能需求

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| R1 | 书源/订阅源支持标签+分组两模式切换 | 用户可在配置对话框切换标签模式（Tab平铺）和分组模式（文件夹） |
| R2 | 修复按类型分组一级页面不生效 + 支持两维度组合 | 按类型分组一级页面能正确显示类型文件夹，点击后正确筛选；用户可按源类型和源分组组合筛选 |
| R3 | 订阅源二级设置页面为列表展示 | 点击文件夹进入后显示列表，不延续文件夹布局，改回原来的列表 |
| R4 | 搜索框参考书架实现 | 搜索框与标签/分组模式配合，不回填 type:/group: 到搜索框 |
| R5 | 视频缓存大小可通过 Spinner 下拉选择 | 设置界面有下拉选择项，可选 50/100/200/500 MB |
| R6 | 视频倍速保留 15x 不动 | 无需代码修改（用户选方案C） |

### 非功能需求

- 不破坏现有书源/订阅源管理功能
- 不改变 BookSource/RssSource 数据模型
- 编译通过，App 启动不崩溃

## Scenarios

### 场景1: 用户切换标签模式查看书源

1. 用户打开书源管理
2. 用户打开配置对话框，选择"标签模式"
3. 首屏变为 Tab 平铺展示分组标签
4. 用户点击某个标签，展示该分组下的书源列表

### 场景2: 用户切换分组模式查看书源

1. 用户打开书源管理
2. 用户打开配置对话框，选择"分组模式"
3. 首屏变为文件夹卡片展示分组
4. 用户点击某个文件夹，进入该分组查看书源列表

### 场景3: 用户按源类型+源分组两维度筛选

1. 用户打开书源管理
2. 用户选择源类型="视频"，源分组="推荐"
3. 展示同时满足两个维度的书源

### 场景4: 用户调整视频缓存大小

1. 用户打开视频设置
2. 用户找到"缓存大小"下拉选择项
3. 用户选择 200MB
4. 重启 App 后缓存容量生效

### 场景5: 用户使用高倍速播放

1. 用户播放视频
2. 用户打开倍速面板
3. 最高倍速不超过 5x（或高倍速自动静音）
4. 无音频失真问题
