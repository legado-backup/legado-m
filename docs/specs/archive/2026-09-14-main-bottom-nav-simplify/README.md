# 主界面底栏精简（移除统计/搜索框 + 统计页迁移 + 移除订阅源全局搜索）

> 状态标记：`已完成`（2026-09-14 检查点 2 用户验收通过，已归档）

## 功能概述

用户对默认底栏形态不满意，本变更围绕"主界面底栏与统计信息收敛"做四项精简（均为**默认行为**，非删除能力）：

1. **底栏移除「统计」Tab**：默认底栏由 5 项（书架/发现/订阅/统计/我的）收敛为 4 项（书架/发现/订阅/我的）。
2. **阅读统计页迁至「我的 → 工具 → 阅读记录」**：原底栏「统计」Tab 的阅读统计仪表盘（`ReadRecordFragment`）作为独立子页，由「我的-工具-阅读记录」入口打开；废掉原底栏 Tab。
3. **主题/底栏设置体系联动清理**：底栏项管理弹窗与底栏图标编辑弹窗中的「统计」条目随配置源移除而自动消失。
4. **默认底栏右下角搜索框默认隐藏**：floating 底栏默认不再显示右下角搜索按钮；主题/外观体系（外观管理预设、其他设置开关、自定义套装默认值）同步对齐，**保留**用户自定义套装可编辑 `hideSearchInFloatingStyle` 的能力。
5. **「我的 → 工具 → 订阅源全局搜索」菜单移除**：订阅 Tab 顶栏已有全局搜索按钮（弹 `RssSearchActivity`），该菜单冗余，移除入口行（`RssSearchActivity` 本身保留）。

## 核心能力

| 能力 | 变更前 | 变更后 |
|------|--------|--------|
| 默认底栏 | 书架/发现/订阅/统计/我的 | 书架/发现/订阅/我的 |
| 阅读统计页入口 | 底栏 Tab（`ReadRecordFragment`） | 「我的 → 工具 → 阅读记录」（宿主 Activity 承载） |
| 侧边栏（sidebar） | 含「统计」项 | 不含「统计」项 |
| 底栏项管理弹窗（底栏管理页） | 含「统计」开关/排序 | 不含「统计」项 |
| 底栏图标编辑弹窗 | 含「统计」图标配置 | 不含「统计」图标行 |
| floating 底栏右下搜索框 | 默认显示 | 默认隐藏（自定义套装可重新开启） |
| 其他设置「浮动底栏隐藏搜索」开关 | 默认关（显示搜索） | 默认开（隐藏搜索） |
| 「我的-工具」 | 含「订阅源全局搜索」行 | 移除该行 |

## 约束与保留项

- `ReadRecordActivity`（阅读记录列表页）**保留**：桌面小组件（阅读排行/阅读目标）点击仍进入该页，本变更不触碰。
- `RssSearchActivity` **保留**：订阅 Tab 顶栏搜索按钮、订阅源内搜索继续使用。
- 自定义底栏套装（`NavigationBarIconConfig` 非 default 包）的 `hideSearchInFloatingStyle` 编辑能力保留；其 icons 中残留的 `readRecord` 键静默忽略（`items` 白名单驱动 apply）。
- 老用户 `mainBottomNavItems` 预存值若含 `readRecord` key，`MainBottomNavConfig.normalize()` 按 specs 白名单自动过滤。
