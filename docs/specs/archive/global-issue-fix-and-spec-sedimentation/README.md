# 全局问题修复与规范沉淀

> ⚠️ 归档待定（2026-08-30 文档规整）：设计停滞超 7 天，如需恢复实施请移回 docs/specs/ 并更新状态

## 功能概述

针对用户 2026-07-16 反馈的 13 项问题进行系统性修复与工程规范沉淀。这些问题暴露了 AI 在开发过程中缺乏全局思考、规范沉淀不足、反复犯同类错误的严重问题。

## 核心能力

1. **修复 6 类 UI Bug**：高亮规则崩溃、订阅源播放器菜单丢失、返回按钮失效、单源线程数配置缺失、视频弹框样式不搭
2. **解决数据库升级覆盖安装问题**：正确的 migration 设计而非让用户卸载重装
3. **校验逻辑重构**：参考调试模式的真实校验，多线程维度并发，关键元素获取程度加权
4. **lastHost 字段设计修正**：三层回填（使用/调试/校验）+ 域名分组按"真实地址+源类型"合并
5. **工程规范沉淀机制**：防反复犯错，建立"错误→沉淀→子规范→主规范引用"闭环
6. **全局思考检查清单**：前端入口、后端接口、数据库改动、覆盖安装影响评估
