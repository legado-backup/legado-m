# Repo Cleanup - 仓库废弃文件清理

## 概述

清理项目中提交到远程仓库的废弃临时文件、备份文件、构建产物和临时分析文档，减少仓库体积并消除安全风险。

## 问题

- 仓库含 2999 个跟踪文件，其中包含大量废弃文件（备份/构建产物/临时文档）
- 签名密钥 `.jks` 提交到仓库存在安全风险
- 临时分析文档 `docs/temp-analysis/` 污染仓库结构
- `.gitignore` 不完善，同类文件可能再次被提交

## 排查发现

| 类别 | 数量 | 体积 |
|------|------|------|
| 明确废弃（可安全删除） | 8 项 | ~2.5MB |
| 安全风险（需改造） | 1 项 | - |
| 需确认（Skill 脚本） | 4 项 | - |
