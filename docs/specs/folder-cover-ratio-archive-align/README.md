# 文件夹封面比例对齐 Archive（folder-cover-ratio-archive-align）

## 功能概述
修复书架页与发现页"文件夹模式"下文件夹封面宽高比不协调、图片被拉长的问题。将文件夹封面比例从当前自定的 **0.7（7:10，瘦高竖版）** 对齐为 **阅读Archive/原版 `CoverImageView` 的固定宽高比 4:3（0.75）**，消除方形/横版自定义封面被竖向过度放大裁剪的视觉失真。

## 核心能力
- 书架文件夹网格封面比例 0.7 → 0.75
- 发现页文件夹网格封面比例 0.7 → 0.75
- View 版文件夹卡片(XML)比例 0.7 → 0.75
- 保持 centerCrop 语义不变，仅"目标容器宽高比"对齐 Archive
