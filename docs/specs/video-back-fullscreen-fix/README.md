# 视频播放器返回按钮修复 + 全屏按钮迁移 + 真全屏优化

## 功能概述

修复订阅源视频播放器左上角返回按钮所有版本不生效的 Bug，将全屏按钮从底部居中迁移到右侧功能区，并将当前"伪全屏"升级为真正的沉浸式全屏。

## 核心能力

1. **返回按钮修复**：左上角返回按钮点击可正确退出播放器
2. **全屏按钮迁移**：全屏按钮移到右侧功能区，随整体隐藏/显示
3. **真全屏**：横屏全屏时播放器铺满整个屏幕（含原 TitleBar 区域），状态栏/导航栏完全隐藏
