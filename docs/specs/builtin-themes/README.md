# 新增 8 个内置主题

> 状态：✅ 已完成

## 功能概述

在现有 4 个内置主题基础上，新增 8 个精心设计的内置主题（5 日间 + 3 夜间），覆盖护眼绿、莫兰迪灰调、海洋青、薰衣草紫、琥珀暖调、暗夜绿、暗夜蓝、暗夜紫等主流设计风格。

## 核心能力

- 5 个日间主题：绿意、莫兰迪、海洋、薰衣草、琥珀
- 3 个夜间主题：暗夜绿、暗夜蓝、暗夜紫
- 全部 WCAG AA 对比度验证通过
- 遵循 Material Design 色彩规范

## 设计亮点

| 主题 | 风格 | 核心特色 |
|------|------|---------|
| 绿意 | 护眼绿 | 经典中文阅读 App 首选，低视网膜刺激 |
| 莫兰迪 | 高级灰调 | 2024-2026 最热门风格，低饱和度温润感 |
| 海洋 | 冷静青绿 | 降低焦虑感，深度阅读专注 |
| 薰衣草 | 优雅浅紫 | 年轻用户喜爱，紫绿互补色对比 |
| 琥珀 | 暖调书香 | 模拟羊皮纸质感，蓝光最低 |
| 暗夜绿 | 夜间护眼 | OLED 友好 + 绿色低色温高亮 |
| 暗夜蓝 | 夜间专业 | M3 推荐 #121212，Gmail/YouTube 同款 |
| 暗夜紫 | 夜间个性 | Discord/Spotify 风格，星空氛围 |
