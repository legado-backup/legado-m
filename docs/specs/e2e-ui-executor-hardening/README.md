## 触发背景

V3 E2E 测试基础设施（阶段 1-14、16-21、22.1-22.2）已完成，但实测 TC-F-P0-1-01 暴露三个缺陷：

1. **click 找不到元素**：PreferenceScreen 长列表（如"其它设置"页面"调试工具"在底部）需滚动才能看到，但 click 不会自动滚动 → pass_rate=1.9%
2. **自愈误判**：元素未找到时误重启 atx-agent，但 atx 不是问题根源，浪费 30s 且掩盖真问题
3. **失败后污染**：步骤失败后不跳过后续步骤，在错误页面执行导致证据污染

## 核心能力

| 能力 | 价值 |
|------|------|
| click 滚动查找 | 设备无关地定位长列表元素，换设备不失效 |
| 自愈区分 | 元素未找到→重试；App 崩溃→重启 App，不误重启 atx |
| 失败跳过 | 步骤失败后后续标记 SKIPPED，证据干净 |
