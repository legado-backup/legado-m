**开发完成（L2 真机验证通过，待用户验收）**（2026-09-06）

## 功能概述
本批次处理 4 个用户反馈问题，均为存量修复/迭代：

1. **崩溃弹框回归修复**：release 包无崩溃也反复弹"检测到崩溃"确认框（MainActivity 弹框被移出 appCrash 条件块）；辅因：崩溃文件写盘静默失败导致"有提示无日志"。
2. **视频书源沉浸式左下角补多线路多集**：对齐视频订阅源体验，无卷书源在数据层回退包装单线路，UI 零改动。
3. **经典发现页三点菜单 Bug 修复 + 全前端空实现清理**：`menu_group` 有实现但点击无反应（弹框 Bug，真机复现定位修复）；清理全量扫描出的死菜单项（`menu_check_rss_source`、`content_select_action` 3 项）。
4. **经典订阅头部收口**：搜索留外面，其余操作（星标/刷新/阅读记录/订阅源管理/布局设置/分组管理）收口到三点菜单；删除分组信息弹窗列举。
