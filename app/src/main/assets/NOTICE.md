# 第三方素材与字体 · 许可与来源

> 本清单列出随应用分发的第三方素材、字体与脚本库的来源及许可，供用户与合规审计核对。
> 内置阅读页模板的逐项素材登记（名称 / 类型 / 作者 / 来源地址 / 许可 / SHA-256）见
> `assets/reader/<模板 id>/sources.json`。

---

## 一、字体

- 应用不内联第三方字体文件，正文与装饰使用系统字族（Noto / Source Han，SIL Open Font License 1.1）。
- 原「霓虹夜行」「星图」主题内嵌的 Orbitron / Share Tech Mono 字体子集已随该两套主题于 2026-10-17 移除。

## 二、内置主题素材

| 主题 | 素材 | 来源 | 权利状态 |
|------|------|------|---------|
| 幽夜回廊（`builtin.dungeon-hud`） | 角色分层部件帧、4 种怪物动作帧、村民 NPC 分层部件、建筑陈设小图、区域底图（大教堂全景 / 城镇屋舍 / 墓道地面）、石墙纹理、左右竖带装饰 | 用户提供的解密资源（AES 加密资源包提取的原始 PNG） | 未获授权，版权归原权利方 |

- 素材按原始分辨率内联，仅按帧横向拼接为精灵表，像素无改动；区域底图按等比例降采样，不做拉伸。
- 逐项路径与 SHA-256 登记在 `assets/reader/builtin.dungeon-hud/sources.json`，
  由 `tools/reader-templates/prepare-dungeon-hud-assets.py` 与 `build-dungeon-hud.py` 重放生成。
- 本主题为非官方主题，不代表原作方；素材不声明为开源或 CC0；主题内不含原作角色名、Logo 与原作文案。
- 页眉暗幕、页脚控制台框线、斩击闪光、道具与石柱为 CSS 自绘，随应用分发。

## 四、素材准入要求

1. 不内置第三方 IP 的名称与文案：不含角色名、Logo 与原作文案，页眉页脚文字均为自撰。
2. 素材来源仅限：项目原创、CC0 / 公有领域、用户提供并明确授权入库（附非官方声明）。
3. 每项素材须有可核查来源与 SHA-256 登记。
4. 成人向与恐怖向素材一律剔除，不随包分发。
5. 用户自行导入的第三方模板仅限本地使用，导出与再分发的授权由用户自行确认。
