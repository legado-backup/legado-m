# replaceRegex净化模式

## 适用场景
去除正文中的广告、重复的章节标题、水印文字等干扰内容。

## 修复源示例
- 奇书塔
- PO18

## 代码片段
```json
{
  "ruleContent": {
    "content": "div.content@html",
    "replaceRegex": "##<div class=\"ad\">[\\s\\S]*?</div>|本章未完.*?点击下一页继续|【.*?广告.*?】##"
  }
}
```

## 注意事项
- 正则需转义：`##正则1|正则2##` 格式，多个规则用 `|` 分隔
- 注意贪婪匹配：`.*?` 非贪婪 vs `.*` 贪婪，去广告块时通常用非贪婪
- `[\s\S]` 匹配任意字符（含换行），比 `.` 更安全（`.` 默认不匹配换行）
- 正则中的反斜杠在 JSON 中需双重转义：`\\d` 而非 `\d`
- 测试时先用单个规则验证，确认无误后再组合多个规则
